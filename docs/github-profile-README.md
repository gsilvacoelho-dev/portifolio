## 🔥 Projetos em Destaque

- 🥗 **[NutriUAI](https://nutriuai.com.br/)** — produto com IA generativa, **em produção**  
  Gera dietas e planos de treino personalizados. O prompt é montado em tempo de execução com o
  gasto energético calculado (Mifflin-St Jeor), as restrições do usuário e alimentos da tabela
  TACO — a IA escreve e adapta, mas os números vêm de fora dela. Inclui assistente
  conversacional sobre a API da OpenAI.  
  `React` `TypeScript` `Supabase` `OpenAI API` `Prompt Engineering`  
  [`🌐 nutriuai.com.br`](https://nutriuai.com.br/)

- 🎮 **[Digita Brasil](https://digitabrasil.site/)** — cliente público  
  Plataforma gamificada de reforço escolar entregue para a **Prefeitura de Várzea da Palma/MG**.
  Requisito levantado direto com o cliente, escopo definido e plataforma no ar.  
  `React` `TypeScript` `Tailwind CSS`  
  [`🌐 digitabrasil.site`](https://digitabrasil.site/)

- 📊 **[5S Manager](https://github.com/gsilvacoelho-dev/5S-Manager)** — ferramenta interna  
  Trocou auditorias em papel e planilha por indicadores por setor e relatórios automáticos:
  a gestão passa a ver onde agir em vez de compilar planilha.  
  `Python` `Flask` `SQLite` `Bootstrap`  
  [`💻 Código`](https://github.com/gsilvacoelho-dev/5S-Manager)
